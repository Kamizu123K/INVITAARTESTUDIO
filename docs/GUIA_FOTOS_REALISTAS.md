# Fotos realistas integradas

Se modificó el proyecto para que el catálogo muestre fotos realistas en las tarjetas y en la vista rápida.

## Ubicación de imágenes
Las fotos están en:

`assets/catalogo-realista/`

Todas están en formato PNG.

## Cambios realizados
- Se dejaron solo las 12 invitaciones con link real de Netlify.
- Se eliminaron plantillas sin link real o con enlaces demo.
- Se agregó `imageUrl` a cada plantilla en `js/data/seedData.js`.
- Se actualizó la vista pública del catálogo.
- Se actualizó la vista rápida/modal para mostrar la foto realista.
- Se cambió la clave de localStorage para evitar datos antiguos en el navegador.
