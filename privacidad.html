Volver

Política de privacidad

Invita Arte Studio solicita únicamente datos necesarios para crear y entregar invitaciones digitales: nombre, correo, teléfono, datos del evento, preferencias de diseño y confirmación de asistencia cuando corresponda.

La plataforma está pensada para trabajar con autenticación por correo, roles internos, HTTPS, validación de formularios y reglas de seguridad en Supabase. No se debe guardar información sensible que no sea necesaria para el pedido.

Uso de datos

Los datos se usan para registrar solicitudes, calcular cotizaciones, preparar diseños, controlar versiones, entregar enlaces digitales y permitir seguimiento del estado del pedido.

Derechos del usuario

El cliente puede solicitar corrección o eliminación de información relacionada con su pedido, salvo datos mínimos requeridos por control administrativo o comprobantes.
